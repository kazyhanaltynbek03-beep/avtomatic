# QOR client test

## Marketplace API
Open **Интеграции → Добавить**. Choose company and marketplace. The API fields appear in the same window:
- Kaspi: API Token
- Wildberries: API Token
- Ozon: Client ID + API Key
After **Провести**, QOR stores the secret encrypted and starts connection check/sync.

## Excel / CSV
Open **Импорт / Экспорт** and choose data type: Products, Sales, Purchases, Stock, Expenses, B2B, Marketplace reports, Bank.
Upload XLSX/CSV. QOR auto-matches common Russian/Kazakh/English headers and shows the mapping for confirmation.
For offline sales, select the company in QOR first. If an Offline account exists, QOR fills it automatically. Products can be matched by SKU/article.
Always review the preview before confirming the import.
