# Матрица реализации

Источник: 16 разделов ТЗ в сообщении пользователя. Отдельные файл ТЗ и визуальный референс в текущем сообщении отсутствовали; недоступные вложения не считаются изученными.

| Требование | Состояние |
|---|---|
| React / backend / БД / migrations | React/Vite + FastAPI + SQLAlchemy + PostgreSQL, две Alembic migrations |
| Один склад, несколько компаний и каналов | Реализовано; у партий есть владелец; Owner видит консолидированный отчёт |
| Закупки и партии с разной стоимостью | Реализовано, дополнительные расходы распределяются в стоимость партии |
| Revenue / COGS / GP / NP / CF / остатки / долг | Реализовано и проверено; целые тиыны, отдельные денежные операции |
| FIFO / частичный возврат / округления | Реализовано и проверено |
| Dashboard, периоды, графики, top/slow/alerts | Реализовано |
| AI Business Assistant | Реальный OpenAI API слой с read-only function; проверен mock, живой API требует ключ |
| Product Cards с фото | API слой + выбор загруженного фото и фактов; живой API не проверен |
| AI Designer | Генерация через Images API; сохранение изображения; живой API не проверен; редактирование фото через provider image-edit endpoint не реализовано |
| Market/Niche | Пользовательские наблюдения с источником/датой, эвристический score; без автоматического сбора рыночной статистики |
| Product Calculator | Реальный детерминированный сценарный расчёт |
| Forecast | Детерминированный прогноз по среднему, минимум 14 дней/7 дат с продажами; без сезонной модели |
| Kaspi/WB/Ozon | Account models, UI, очередь, interface, CSV и demo; live HTTP adapters НЕ реализованы |
| Импорт/экспорт 8 типов | Реализовано CSV/XLSX, mapping, preview, ошибки, атомарность, дубли |
| Offline / B2B / задолженность | Реализовано, клиент, срок оплаты, платежи, просрочка |
| Бухгалтерский раздел | Управленческий P&L, активы и расчёты, выгрузки; без регламентированного учёта |
| Документы / файловое хранилище | Приватные uploads; авторизованное скачивание; счёт HTML, выгрузка Excel |
| 6 ролей / сессии / аудит | Реализовано; company scopes, Argon2, CSRF |
| Desktop/tablet/mobile | Реализовано и проверено браузером |
| Docker / seed / env / README | Подготовлено; Docker daemon в среде отсутствует, сборка контейнера не проверялась |
| Полная приёмка PostgreSQL | SQL-схема сгенерирована; сервер PostgreSQL в текущей среде запустить нельзя, runtime/concurrency gate остаётся перед production |

Результат — работающая первая версия для локальной демонстрации и последующей приёмки, а не заявление о полном выполнении всех внешних интеграций и боевой готовности.
