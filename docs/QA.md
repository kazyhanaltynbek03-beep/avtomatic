# Проверка сборки

Дата: 2026-10-05. Backend: Python 3.12, SQLite для runtime-проверки. Frontend: production Vite build, Chromium headless.

## Автоматические проверки

`pytest -q`: **37 passed**. Проверены:

- Закупка не уменьшает прибыль, оплата отдельно уменьшает деньги.
- FIFO по двум партиям, распределение дополнительных затрат, сохранение тиынов при округлении.
- Частичные/полные возвраты в исходные партии; возврат в другом отчётном периоде.
- Исторический склад и Cash Flow, B2B-долг и частичная оплата.
- Запрет перепродажи остатков, чужих партий/аккаунтов, избыточного возврата, переплаты и нулевого платежа.
- Отрицательная корректировка склада признаёт расход; запрет складского заднего числа.
- CRUD справочника, audit log, неизменяемость проведённых документов.
- Авторизация, CSRF, logout, смена пароля с отзывом сессий, company scope и RBAC.
- CSV/XLSX parse/export, защита от formula injection, preview без записи, ошибки, атомарный confirm, повторный импорт.
- Импорт товаров, продаж, закупок, остатков, расходов, банка, B2B и marketplace reports.
- Очередь demo connector без финансовых записей, честная ошибка live adapter и отсутствующего AI key.
- AI function-calling с mock-провайдером и реальными данными тестовой БД; запрет чужого job.
- Калькулятор, неполные данные niche score, фильтр канала, авторизованное скачивание и счёт.

Тесты всегда создают отдельную временную БД и не используют рабочую DATABASE_URL.

## Миграции и сборка

- `alembic upgrade head → downgrade base → upgrade head`: выполнено на отдельной SQLite.
- `alembic check`: No new upgrade operations detected.
- PostgreSQL SQL сгенерирован через `alembic upgrade head --sql`.
- `npm run build`: успешно. Неблокирующее предупреждение о JS chunk >500 kB; сжатый bundle около 201 kB.

## Реальные браузерные сценарии

- Вход Owner, загрузка Dashboard и всех 32 остальных рабочих разделов/маршрутов: без JavaScript runtime errors.
- Создание, поиск, редактирование и удаление тестового товара.
- Проведение многострочной формы закупки (проверена одна строка через UI, несколько — API-тестом), продажи и возврата через формы.
- CSV: загрузка, автоматический mapping, preview, confirm. Исправлена и повторно проверена гонка при быстрой загрузке файла до загрузки описания колонок.
- Калькулятор: отправка параметров, вывод результата.
- Мобильное меню и форма, desktop 1440 px, tablet 820 px, mobile 390 px. После исправления ширина документа равна ширине viewport на 390 и 820 px.
- Финальная повторная проверка: CSV UI PASS; Mobile PASS; JS errors: [].

## Что не проверено

- Живые OpenAI Responses/Images вызовы: ключ клиента не предоставлен. Mock не заменяет живой контрактный тест.
- Сетевые API Kaspi/WB/Ozon: live adapters не реализованы; интерфейсы, очередь, CSV/demo проверены.
- Docker image build и Compose runtime: Docker daemon недоступен в среде.
- PostgreSQL runtime, блокировки при конкурентных запросах и нагрузка: PostgreSQL не запущен из-за ограничений среды на системного пользователя. SQL-генерация не заменяет эти проверки.
- Реальные бухгалтерские/налоговые регламенты, расчёт налогов, ЭСФ и банковская сверка не реализованы.

Пройденные проверки подтверждают указанные сценарии, но не являются гарантией отсутствия любых ошибок или полной production-приёмкой.
