## Status vocabulary
- **SUPPORTED**: verified in official documentation for the stated API/version and scope.
- **LIMITED**: documented with constraints such as pagination, scheme, account eligibility, or report delay.
- **UNAVAILABLE**: official documentation explicitly states no API capability for the defined operation.
- **REQUIRES VERIFICATION**: documentation, region, version, access scope or ERP implementation is not confirmed.

See root `MARKETPLACE_API_MATRIX.md` for sources and domain-level status. A marketplace API capability does not prove QOR has integrated it.
